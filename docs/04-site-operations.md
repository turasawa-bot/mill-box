# ゼネコン作業所での集計方法

## 集計の5つのキー

実務では、次の5つのキーで書類を整理すると破綻しにくい。

| キー | 理由 |
| --- | --- |
| 打込み日 | 圧縮強度・日報・写真と一致させやすい |
| 工区/打設ロット | 中間検査や是正範囲の切り分けに必要 |
| 部位 | 基礎、耐圧版、地中梁、柱、壁、梁、スラブ等で追える |
| 計画調合No / 配合No | 配合計画書・納入書・試験結果を結びやすい |
| 工場名 | 複数工場が入るときの取り違え防止 |

大阪市の様式自体が「計画調合No」「打込箇所」「打込時期」「打込容積」「スランプ」「空気量」「温度」「塩化物量」「圧縮強度」「養生方法」「製造会社・工場名」を軸にしているので、現場の集計軸もほぼこれに寄る。

## 現場の標準的な集計フロー

```
配合計画書を受領
  |
  v
打設計画表に「配合No・打設日・部位・予定数量」を登録
  |
  v
各車の納入書を回収し、打設ロットに紐付け
  |
  v
フレッシュ試験票と供試体番号をそのロットに紐付け
  |
  v
7日・28日の圧縮強度結果を追記
  |
  v
月次/検査前に「施工結果報告書」へ転記
  |
  v
工事監理者が総括し、中間/完了検査へ
```

この流れの肝は、**原票管理ではなくロット管理**。納入書の束だけでは検査対応ができないので、最終的には「打設ロット台帳」に落とす必要がある。BCJの一覧でも、施工結果報告書を表に、原票は裏付け資料として持つ形が読み取れる。

## 枚数とリードタイムの目安

以下は法定固定値ではなく、様式運用と試験頻度から見た実務レンジ。

| 書類 | 枚数の増え方 | 典型リードタイム |
| --- | --- | --- |
| 施工計画報告書 | 1案件1式 | 初回打設の1〜2週間前に固めることが多い |
| 配合計画書 | 1配合Noごと | 初回打設の数日前 |
| 納入書 | 1運搬車ごと | 当日即時 |
| フレッシュ試験報告 | 1試験ロットごと | 当日〜翌日 |
| 圧縮強度試験報告 | 1試験ロットごと | 7日・28日・必要に応じ91日 |
| 骨材試験報告 | 1回/月ごと | 数日〜1週間 |
| 施工結果報告書 | 1検査回ごと1式 | 検査前数日〜1週間 |
| 工事監理・工事状況報告書 | 1検査回ごと | 検査直前 |

検査申請の締切は機関差がある。たとえば横浜市は中間検査申請を**検査予定日の4日前から前日まで**、BCJの完了検査案内は**検査予約は2週間前目安、書類は1週間前まで**を案内している。

## 「確認検査で本当に効く書類」と「裏取り書類」

| 位置づけ | 書類 | コメント |
| --- | --- | --- |
| 表紙 | 施工結果報告書 | 検査側が最初に読む |
| 表紙 | 工事監理・工事状況報告書 | 工事監理者の公式見解 |
| 裏付け | 配合計画書 | その配合でよいか |
| 裏付け | 納入書 | その車がその条件だったか |
| 裏付け | フレッシュ試験 | 荷卸し時点で適正か |
| 裏付け | 圧縮強度試験 | 設計基準強度を満たすか |
| 裏付け | 骨材試験・JIS資料・認定書 | 材料の適法性・安定性 |
| 裏付け | 写真 | 書類で見えない施工状況の証拠 |

BCJの構造関係書類一覧では、コンクリート工事施工結果報告書が提出必須で、配合計画書や圧縮強度試験報告書などは提示対象と整理されている。日本ERIの中間・完了検査チェックシートも、関与する写真・試験結果の準備を求めている。

## 検査の流れ

1. コンクリート工事施工結果報告書（表紙）の試験結果一覧を確認。不審に感じた打設ロットの関連資料提出を求める。
2. 「1」で指示したロットに紐づく資料を確認。（配合計画書・フレッシュ試験報告・受入写真・圧縮強度試験報告・納入伝票一式）
