# Claude Code学習用_生コン圧縮強度試験様式

## 目的
この文書は、コンクリート圧縮強度試験成績書の様式を、Claude Code が参照・再利用しやすいように Markdown 化したものである。

用途:
- PDF/画像から様式を判定する
- 抽出対象フィールドを固定する
- 別案件の報告書を同一スキーマで構造化する
- 様式差分を比較する
- 将来的に JSON / CSV / DB スキーマへ変換する

---

## 収録した様式の種類

### 1. 日東コン系_普通強度_圧縮強度試験成績書
- 単票1ページ完結型
- 同一様式で「構造体用」と「使用するコンクリートの強度確認（調合管理用相当）」の2種類がある
- 供試体3本、平均値1つの構成
- 下段に Fc / Fd / Fq / S / Fm / FN の一覧がある

### 2. 日東コン系_高強度_圧縮強度試験成績書
- 単票1ページ完結型
- 高強度コンクリート用
- 供試体を 1回目 / 2回目 / 3回目 の3グループで記録
- グループ平均値と全体平均値を持つ
- 建築基準法第37条認定番号欄がある

### 3. 宮城県生コンクリート大崎技術センター系_3ページ報告書
- 表紙 + 依頼情報 + 試験結果 の3ページ構成
- 一部セットでは別紙の写真ページが付属
- さらに納入生コン工場発行の「コンクリート強度試験成績書」が付属する場合がある
- 同一案件内で複数ロット・複数打設箇所のセットが綴じられている

---

## 様式判定ルール

以下のルールで様式を判定する。

- 1ページで完結し、右上に「受付番号 / 受付日 / 報告日」があり、下段に Fc / Fd / Fq / S / Fm / FN があれば `nittocon_normal_strength_test_report`
- 1ページで完結し、「高強度」「建築基準法第37条認定番号」「1回目平均値 / 2回目平均値 / 3回目平均値」があれば `nittocon_high_strength_test_report`
- 3ページ1組で、表紙に JAB ロゴ、様式C-0001 / C-0002 / C-0003 があり、3ページ目が「圧縮強度試験結果」であれば `osaki_3page_compression_strength_report`
- 写真だけのページは `photo_attachment`
- 工場押印付きで、表タイトルが「コンクリート強度試験成績書」、中央に試験表があるものは `plant_issued_strength_report`

## 抽出優先順位

1. 受付番号 / 報告番号
2. 工事名
3. 打込み箇所
4. 呼び強度
5. 採取日 / 試験日 / 材齢
6. 供試体ごとの圧縮強度
7. 平均値
8. 判定
9. 生コン工場名
10. 試験機関名

## 正規化の考え方

- `呼び方` は元帳票の表記を保持する
- `呼び強度` は数値だけ別フィールドに切り出せる場合は切り出す
- 日付は原文保持と ISO 形式の両方を持てる設計が望ましい
- `打込み箇所` は原文を保持しつつ、建物/棟/階/部位へ分解可能なら別途分解する
- 供試体番号は文字列として保持する
- `平均値` はグループ平均と総平均を区別する

## 運用メモ
- このMarkdownは、OCRの完全転記ではなく、**様式学習と構造抽出** を主目的に正規化している。
- 実務でのデータ化では、原票画像/PDFへの参照IDを必ず残す。
- 署名・押印・脚注・写真ページは、必要に応じて別オブジェクト化する。
