# 確認検査に向けた生コン書類業務

## 確認検査の実施目的

生コン（レディーミクストコンクリート）の「確認検査」の目的は、「設計図書どおりの品質・性能のコンクリートが、正しい手順で製造され、受入れ・打込みされ、構造体として所要性能を満たすことを、記録（書類）と試験で客観的に確認する」ことです。

現場実務としては次の目的に分解できます。

### 1) 構造安全性・耐久性の確保（要求性能の担保）

- 強度（圧縮強度）が設計基準強度を満たすことの確認（供試体による強度試験など）
- 耐久性に関わる品質（例：水セメント比、単位水量、空気量、塩化物量など）が管理されていることの確認
- 施工上の品質（スランプ・空気量・コンクリート温度など）が許容範囲内で、打込み可能な状態であることの確認

### 2) トレーサビリティの確保（「いつ・どこで・誰が・何を」）

- どの部位に、どの配合・どの工場・どの車番・どの出荷伝票の生コンが入ったかを追える状態にする
- 不具合（強度不足、ひび割れ、材料不適合等）が出た際に、原因切り分け・影響範囲特定・是正判断をできるようにする

### 3) 法令・仕様書・契約への適合の証明（検査・監理への説明責任）

- 建築基準法の完了検査や監理者（設計監理）への説明に耐えるエビデンスを揃える
- JIS認証工場の製造管理や、施工計画・品質計画に沿って運用されていることを示す
- 発注者・監理者・行政に対して「適合している」ことを客観的に示す（後から揉めない）

### 4) リスク低減（手戻り・補修・工期遅延・コストの回避）

- 受入れ時点でNG（スランプ不良、空気量逸脱、温度異常、経過時間超過等）を止め、構造体不具合の発生確率を下げる
- もし逸脱が起きても、早期に検知して影響を最小化する（打込み中止、追加試験、配合変更、補修判断など）

現場の「生コン書類業務」としては、この目的を達成するために、配合報告書・出荷伝票・受入検査記録（スランプ/空気量/温度/塩化物等）・供試体管理/強度試験成績・打込み記録・不適合時の対応記録といった一連の証跡を部位単位で揃えていく。
