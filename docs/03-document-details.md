# 書類ごとの役割・作成者・集計方法

## 1) コンクリート工事施工計画報告書

| 項目 | 内容 |
| --- | --- |
| 目的 | 打設前に、どういう配合・試験・品質管理で進めるかを行政/検査側に先出しする |
| 主な根拠 | 自治体細則・要綱運用。大阪市では**コンクリート工事着手前まで**に提出。東京都でも細則・要綱に基づく報告運用あり |
| 作成者 | 実務上は施工者が案を作り、**工事監理者名で報告**する運用が多い |
| 作成時期 | 初回打設前 |
| 主な記載 | 建物概要、施工体制、打込計画、計画調合No、試験計画、劣化対策、塩害/ASR対策など |
| 現場での集計単位 | **配合No単位**でまとめる |
| 枚数感 | 1式。表紙1〜2枚＋打込計画表数枚が典型 |
| リードタイム | 1〜2週間前に固める現場が多いが、制度上は「着手前まで」 |

大阪市の様式では、報告書に「計画調合No」「打込箇所」「打込時期」「コンクリート種類」「呼び強度」「スランプ」「空気量」「温度」「塩化物量」「圧縮強度」「養生方法」まで載せる前提になっています。東京都でも、施工計画・施工結果報告等の運用があり、関係者向け実務講習の対象に工事監理担当者や現場の工事管理担当者が含まれています。

## 2) コンクリート配合計画書

| 項目 | 内容 |
| --- | --- |
| 目的 | その配合が設計条件・仕様条件を満たすことの事前証明 |
| 主な根拠 | 公共建築工事標準仕様書では、**製造に先立って提出**。JIS認証の品質管理文書でも「配合計画書及び基礎資料」が報告対象 |
| 作成者 | **生コン工場** |
| 作成時期 | 初回製造前、通常は初回打設前 |
| 現場集計 | **配合Noをキー**に保管し、施工計画報告書・施工結果報告書と紐付け |
| 枚数感 | **1配合Noごとに1式**。標準配合、修正配合、基礎資料が付くと数枚〜十数枚 |
| リードタイム | 3〜7営業日前に現場へ回ることが多いが、制度上は「製造前」 |

公共建築工事標準仕様書は、配合計画書を「材料、調合設計の基礎資料、計算書等を含むもの」とし、製造前提出を求めています。JIS認証側の品質管理文書でも、報告の代表書類として配合計画書と納入書が明示されています。

## 3) 納入書（納品書・出荷伝票）

| 項目 | 内容 |
| --- | --- |
| 目的 | その車の生コンが、発注条件どおり出荷・納入されたことの証跡 |
| 主な根拠 | 公共建築工事標準仕様書では、**各運搬車の納入書**で条件適合を確認 |
| 作成者 | **生コン工場** |
| 作成時期 | 各車出荷時〜荷卸し時 |
| 現場集計 | **打設日 x 工区 x 部位 x 配合No x 車番** で並べる |
| 枚数感 | **1運搬車1枚**が基本。枚数はほぼ車両台数分 |
| リードタイム | 当日即時 |

この書類が、現場で最も枚数が膨らみやすい。例えば1日150m3を4.5〜5.0m3/車で打つと、納入書は概ね30枚前後になる。これは法定枚数ではなく、**車数連動**。

## 4) フレッシュコンクリート試験報告書

| 項目 | 内容 |
| --- | --- |
| 目的 | 荷卸し時点で、スランプ・空気量・温度・塩化物量などが許容範囲か確認 |
| 主な根拠 | 公共建築工事標準仕様書の試験表。塩化物量は**コンクリート種類ごとに1日1回以上**、かつ150m3超なら150m3ごとに1回以上 |
| 作成者 | 採取試験会社・登録試験所・現場品質管理担当のいずれか。東京都運用では、採取試験会社が施工者等に代わって行う制度がある |
| 作成時期 | 打設当日 |
| 現場集計 | **打設ロット単位**で整理し、納入書・供試体番号と紐付け |
| 枚数感 | **1試験ロット1枚程度** |
| リードタイム | 当日〜翌日 |

公共建築工事標準仕様書では、スランプ許容差は8〜18cmで+/-2.5cm、21cmで+/-1.5cm、空気量許容差は+/-1.5%、塩化物量は0.30kg/m3超なら連続確認を求めています。東京都の採取試験会社制度は、採取・供試体製作・運搬などを施工者等に代わって行う枠組みです。

## 5) コンクリート圧縮強度試験報告書

| 項目 | 内容 |
| --- | --- |
| 目的 | 設計基準強度との関係で必要な強度を満たしているか証明 |
| 主な根拠 | 令74条系、昭56建告1102号、公共建築工事標準仕様書 |
| 作成者 | **登録試験所**が中心 |
| 作成時期 | 供試体採取は打設当日、結果は7日・28日・必要に応じ91日以内 |
| 現場集計 | **打込み日ごと x 打込み工区ごと x 150m3以下の単位ごと** |
| 枚数感 | **1試験ロット1枚程度**。ただし1回の試験は供試体3本が基本 |
| リードタイム | 7日速報、28日確報が基本 |

公共建築工事標準仕様書では、供試体は工事現場で作製し、**1回の試験は3個**、頻度は**打込み日ごと・打込み工区ごと・150m3以下にほぼ均等分割した単位ごと**です。昭56建告1102号も、令74条に基づく強度基準と強度試験を定めています。

## 6) 骨材試験報告書

| 項目 | 内容 |
| --- | --- |
| 目的 | 骨材の品質変動管理、ASR/塩害リスク管理の裏付け |
| 主な根拠 | 地域運用差があるが、大阪市では**工事開始前および工事期間中1回/月**の提出運用 |
| 作成者 | 登録試験所、生コン工場、第三者試験機関 |
| 作成時期 | 着工前、以後月次 |
| 現場集計 | 月別でファイルし、計画報告/結果報告の添付資料に回す |
| 枚数感 | 1回1式 |
| リードタイム | 数日〜1週間程度 |

大阪市の様式では、骨材試験報告書として絶乾密度、吸水率、粒度の測定を月1回提出する運用です。

## 7) コンクリート工事施工結果報告書

| 項目 | 内容 |
| --- | --- |
| 目的 | バラバラの原票を、検査側が読める形に**集計して要約**する中核帳票 |
| 主な根拠 | BCJでは中間/完了時に**2部提出**。大阪市でも中間検査申請時または完了検査申請時に提出 |
| 作成者 | 実務上は施工者がまとめ、**工事監理者名で提出**することが多い |
| 作成時期 | 中間検査前、完了検査前 |
| 現場集計 | **打設日・部位・配合No・数量・試験結果**で一覧化 |
| 枚数感 | 1式。規模次第で2〜数十枚 |
| リードタイム | 検査の数日前〜1週間前に締めるのが一般的 |

BCJの構造関係書類一覧では、コンクリート工事施工結果報告書は提出必須の位置づけです。大阪市の様式は、計画/結果の上下二段で同じ表を使い、打込部位・数量・スランプ・空気量・温度・塩化物量・圧縮強度・養生方法まで一覧化する前提です。

## 8) 工事監理・工事状況報告書 / 申請書第4面

| 項目 | 内容 |
| --- | --- |
| 目的 | 工事監理者が、設計図書と照合して適否を報告する |
| 主な根拠 | H19告示835号、法12条5項運用 |
| 作成者 | **工事監理者** |
| 作成時期 | 中間検査、完了検査 |
| 現場集計 | 施工結果報告書と写真・試験結果を根拠資料として引用 |
| 枚数感 | 数枚 |
| リードタイム | 検査直前 |

国交省の整理では、中間・完了検査の書類検査の主役が「工事監理の状況」です。自治体様式でも、法12条5項の報告は原則として工事監理者が作成・提出するとされています。
