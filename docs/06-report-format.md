# コンクリート施工結果報告書 様式仕様

東京都都市整備局のコンクリート施工結果報告書様式（様式第05号）に基づく。

参照元: https://www.toshiseibi.metro.tokyo.lg.jp/documents/d/toshiseibi/05-

## 報告書ヘッダー部

| フィールド | 内容 | 備考 |
| --- | --- | --- |
| 確認済証番号 | 建築確認済証の番号 | |
| 届出年月日 | 報告書の届出日 | |
| 建築場所 | 工事の所在地 | |
| 建築主 | 建築主の氏名・名称 | |
| 工事名称 | 工事の名称 | |
| 工事施工者 | 施工者の名称 | |
| 工事監理者 | 工事監理者の氏名・名称 | 報告書の名義人 |

## 計画・結果一覧表（メインテーブル）

東京都様式では、計画（上段）と結果（下段）を同一表内で対比する構成が一般的。各打設ロット（打込み回）ごとに1行を使う。

### 列構成

| No. | 列名 | データ型 | 単位 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 打込回 | 整数 | - | 連番 |
| 2 | 打込年月日 | 日付 | - | 実際の打設日 |
| 3 | 打込箇所・部位 | テキスト | - | 例: 基礎、地中梁、1F柱、2Fスラブ等 |
| 4 | コンクリートの種類 | テキスト | - | 普通、軽量、高強度等 |
| 5 | 計画調合No | テキスト | - | 配合計画書の調合番号 |
| 6 | 呼び強度 | 数値 | N/mm2 | 配合計画書に基づく |
| 7 | 設計基準強度(Fc) | 数値 | N/mm2 | 構造図に基づく |
| 8 | スランプ | 数値 | cm | 計画値と実測値 |
| 9 | 空気量 | 数値 | % | 計画値と実測値 |
| 10 | コンクリート温度 | 数値 | 度C | 荷卸し時の温度 |
| 11 | 塩化物量 | 数値 | kg/m3 | 0.30kg/m3以下が基準 |
| 12 | 打込み数量 | 数値 | m3 | 計画数量と実績数量 |
| 13 | 圧縮強度（7日） | 数値 | N/mm2 | 速報値 |
| 14 | 圧縮強度（28日） | 数値 | N/mm2 | 確報値。判定の主対象 |
| 15 | 養生方法 | テキスト | - | 標準養生、現場水中養生等 |
| 16 | 製造会社・工場名 | テキスト | - | JIS認証工場名 |
| 17 | 判定 | テキスト | - | 適/否 |
| 18 | 備考 | テキスト | - | 不適合時の対応等 |

### 計画値と結果値の対比構造

各打設ロットの行において、以下の項目は計画値（上段）と結果値（下段）の二段構成で記載する:

- スランプ: 計画値（指定スランプ）と実測値
- 空気量: 計画値（指定空気量）と実測値
- コンクリート温度: 管理基準値と実測値
- 塩化物量: 管理基準値と実測値
- 打込み数量: 計画数量と実績数量
- 圧縮強度: 必要強度と試験結果値

## 許容値・判定基準

施工結果報告書上で適否判定に用いる主な基準:

| 項目 | 基準 | 根拠 |
| --- | --- | --- |
| スランプ（8〜18cm） | 指定値 +/- 2.5cm | JIS A 5308 / 公共建築工事標準仕様書 |
| スランプ（21cm） | 指定値 +/- 1.5cm | JIS A 5308 / 公共建築工事標準仕様書 |
| 空気量 | 指定値 +/- 1.5% | JIS A 5308 / 公共建築工事標準仕様書 |
| 塩化物量 | 0.30 kg/m3 以下 | 公共建築工事標準仕様書 |
| 圧縮強度（28日） | 1回の試験結果が調合管理強度の85%以上、かつ3回の試験結果の平均が調合管理強度以上 | 昭56建告1102号 |

## プロダクトへの実装考慮事項

### 自動転記マッピング

Step 3（試験結果の自動データ化）で抽出したデータは、以下のように施工結果報告書の列にマッピングする:

| 抽出元 | 抽出データ | マッピング先の列 |
| --- | --- | --- |
| フレッシュ試験報告書 | スランプ実測値 | No.8 スランプ（結果） |
| フレッシュ試験報告書 | 空気量実測値 | No.9 空気量（結果） |
| フレッシュ試験報告書 | コンクリート温度 | No.10 コンクリート温度（結果） |
| フレッシュ試験報告書 | 塩化物量 | No.11 塩化物量（結果） |
| 圧縮強度試験報告書 | 7日強度 | No.13 圧縮強度（7日） |
| 圧縮強度試験報告書 | 28日強度 | No.14 圧縮強度（28日） |
| 配合計画書 | 呼び強度 | No.6 呼び強度 |
| 配合計画書 | 調合No | No.5 計画調合No |
| 配合計画書 | 指定スランプ | No.8 スランプ（計画） |
| 配合計画書 | 指定空気量 | No.9 空気量（計画） |
| 納入伝票 | 打込み数量合計 | No.12 打込み数量（結果） |
| 納入伝票 | 工場名 | No.16 製造会社・工場名 |

### ロット仕分けキー

Step 2（ロット単位の仕分け）で使用する紐付けキー:

1. **打込み日** - 全書類共通で最も信頼性の高いキー
2. **配合No / 調合No** - 配合計画書・納入伝票・試験報告書を横断して紐付け
3. **打込み箇所・部位** - 打設計画書と納入伝票から特定
4. **工場名** - 納入伝票・配合計画書から特定
