# 生コン確認検査_行政庁向け運用標準

## 0. 目的
本書は、ゼネコン建設作業所における、生コンクリートに関する中間検査・完了検査対応を円滑に行うための標準運用を定めるものである。
対象は、行政庁向けの提出・提示資料の準備、現場内の原票回収、台帳化、監理者確認、提出束作成までを含む。

## 1. 想定する書類体系
確認検査対応では、書類は以下の2層で管理する。

### 1.1 表紙書類
- 工事監理報告書または工事監理の状況に関する書類
- コンクリート工事施工計画報告書
- コンクリート工事施工結果報告書

### 1.2 裏付け書類
- 配合計画書
- 納入書
- フレッシュコンクリート試験記録
- 圧縮強度試験報告書
- 骨材試験報告書
- 写真帳
- 必要に応じてJIS適合資料、認定資料、特記仕様書抜粋

## 2. 基本方針
現場では書類単位ではなく、打設ロット単位で管理する。
管理キーは以下とする。

| 管理キー | 内容 |
|---|---|
| 打設日 | コンクリート打込み日 |
| 打設部位 | 基礎、耐圧版、地中梁、柱、壁、梁、スラブ等 |
| 工区 | 東西南北、棟、階、工区など |
| 配合No | 配合計画書と納入書を紐付ける番号 |
| 製造工場 | 生コン工場名 |
| 試験ロットNo | フレッシュ試験・圧縮強度試験を紐付ける番号 |
| 予定数量 | 打設計画上の数量 |
| 実績数量 | 納入実績数量 |

## 3. 業務フロー

### 3.1 着工前から初回打設前
1. 躯体主任が打設計画を作成する。
2. 生コン工場へ配合条件を提示し、配合計画書を受領する。
3. 品質担当が配合計画書の内容を確認する。
4. 必要に応じて施工計画報告書を作成する。
5. 工事監理者へ事前説明を行う。
6. 行政庁提出が必要な場合は、施工計画報告書を提出する。

### 3.2 打設前日まで
1. 打設日、部位、配合No、予定数量を台帳へ登録する。
2. 試験会社へフレッシュ試験・供試体採取を手配する。
3. 納入書の回収担当者を決める。
4. 写真撮影担当者を決める。
5. 当日チェックシートを準備する。

### 3.3 打設当日
1. 各車の納入書を受領する。
2. 納入書に打設日、部位、工区、配合Noを紐付ける。
3. フレッシュ試験を実施する。
4. 供試体を採取し、試験ロットNoを付与する。
5. 写真を撮影する。
6. 当日終了後、原票を回収する。

### 3.4 打設後
1. 当日原票を台帳へ転記する。
2. 試験会社からフレッシュ試験記録を受領し、台帳へ反映する。
3. 7日、28日等の圧縮強度試験結果を受領し、台帳へ反映する。
4. 不適合、未回収、差異があれば是正対応を行う。

### 3.5 検査前
1. 台帳をもとに施工結果報告書を作成する。
2. 写真帳を整理する。
3. 工事監理者へ説明し、確認を受ける。
4. 提出束を作成する。
5. 行政庁または確認検査機関へ提出または提示する。

## 4. 役割分担
| 役割 | 主担当業務 |
|---|---|
| 所長 | 全体承認、提出判断、対外説明 |
| 躯体主任 | 打設計画、当日運営、部位整理、原票回収指示 |
| 品質担当 | 配合確認、試験結果確認、台帳更新、結果報告書作成 |
| 工務/事務 | 書類整理、PDF化、提出束編成、版管理 |
| 試験会社 | フレッシュ試験、供試体採取、圧縮強度試験報告 |
| 生コン工場 | 配合計画書、納入書、工場品質関連資料の提供 |
| 工事監理者 | 施工状況確認、書類確認、監理報告書作成 |
| 行政庁/確認検査機関 | 書類確認、現場検査、受理 |

## 5. 逆算スケジュール
検査日をTとした場合の標準逆算。

| 時点 | 実施事項 |
|---|---|
| T-21日 | 対象打設ロットの確定 |
| T-14日 | 未回収書類の洗い出し、試験未着の督促 |
| T-10日 | 施工結果報告書ドラフト作成開始 |
| T-7日 | 工事監理者へ事前説明、写真帳整理 |
| T-5日 | 提出束ドラフト完成 |
| T-3日 | 所長確認、監理者確認、差替え |
| T-1日 | 最終版確定、印刷またはPDF化 |
| T日 | 検査対応 |

## 8. ファイル命名規則

- `YYYYMMDD_工事名_書類種別_版数.pdf`
- `YYYYMMDD_工事名_ロットID_納入書_車番.pdf`
- `YYYYMMDD_工事名_ロットID_フレッシュ試験.pdf`
- `YYYYMMDD_工事名_ロットID_圧縮強度_28日.pdf`

例:
- `20260410_○○新築工事_施工結果報告書_v01.pdf`
- `20260410_○○新築工事_L001_納入書_12号車.pdf`
